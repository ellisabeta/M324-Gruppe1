# Technische Infrastruktur

**Backend:** Java 17 mit Spring Boot 3.3.5 Framework (Microservices: `flughafen-service`, `flug-service`)

**Datenbank:** MongoDB 7.0 (Containerisiert via Docker, keine externen Cloud-Abhängigkeiten)

**Deployment / Orchestrierung:** Docker & Docker Compose (`docker-compose.deploy.yml`)

**Container Registry:** GitHub Container Registry (GHCR)
